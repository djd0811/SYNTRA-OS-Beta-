# SYNTRA OS

**An Android-inspired custom operating system/interface for the TI-84 Evo.**

SYNTRA OS is a custom software project designed to give the **TI-84 Evo** a modern, Android-inspired experience while working within the calculator's limited hardware, memory, storage, and 320×240 display.

> **SYNTRA OS is an independent community project and is not affiliated with Texas Instruments.**

---

## ✨ Features

SYNTRA is designed around a simple, modern interface with everything optimized for the TI-84 Evo's small screen.

### 🏠 Home Screen
- SYNTRA OS startup screen
- Custom SYNTRA logo
- Date and time display
- App launcher
- Designed specifically for the 320×240 display
- No overlapping or cut-off UI elements

### 📱 Built-in Apps

- 🧮 **Calculator** — calculator interface designed around the TI-84 Evo
- 🎮 **Games** — collection of built-in games
- 📝 **Notes** — create and save up to 10 notes
- 🖼️ **Gallery** — store and view up to 10 pictures
- 📁 **Files** — access stored pictures, notes, and miscellaneous files
- ⚙️ **Settings** — customize SYNTRA

### 🎮 Games

SYNTRA is designed to include lightweight games optimized for the calculator:

- Flappy
- Pong
- Tetris
- Breakout
- Minesweeper
- Space

Each game is designed with the TI-84 Evo's controls and hardware limitations in mind.

## 🖥️ Hardware

SYNTRA OS is specifically designed for the **TI-84 Evo**.

| Specification | Target |
|---|---|
| Device | TI-84 Evo |
| Display | 2.8-inch |
| Resolution | 320 × 240 |
| UI | Custom |
| Input | Built-in calculator keyboard |
| Storage | Optimized for calculator limitations |
| Memory | Designed with RAM restrictions in mind |

Because the TI-84 Evo has significantly fewer resources than a modern computer or phone, SYNTRA prioritizes lightweight code and efficient memory usage.

---

## ⌨️ Controls

SYNTRA uses the calculator's existing keyboard.

The calculator's built-in keys are used for:

- Navigation
- Selecting apps
- Entering text
- Playing games
- Calculator input

For Notes, the calculator's existing **green secondary letters** can be used for typing rather than requiring an on-screen keyboard.

## 💾 Memory & Performance

SYNTRA is being developed with the TI-84 Evo's limitations in mind.

The project aims to:

- Minimize RAM usage
- Minimize storage requirements
- Avoid unnecessary files
- Reduce screen redraws
- Prevent visual flickering
- Keep menus responsive
- Avoid loading large assets unnecessarily
- Keep the interface within the 320×240 display

Performance and memory efficiency are important parts of SYNTRA's development.
